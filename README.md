# Алекс — голосовой ассистент (Android)

Нативный клиент к голосовому ассистенту «Алекс» на домашнем компьютере
(ALEX): слух — faster-whisper medium на видеокарте, голос — F5-TTS (клон
голоса), мозг — DeepSeek через opencode GO.

## Что умеет
- Чат с Алексом: текст ↔ текст
- Голос: удерживайте кнопку микрофона — фраза уходит на сервер, ответ
  приходит голосом и текстом (черёд ответа и расшифровка в заголовках)
- История переписки (хранится на телефоне)
- Настройки: адрес сервера и токен
- Самообновление через GitHub Releases (проверка при старте)

## Сборка
```
./gradlew.bat assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`

## Обновление
Релиз: `gh release create v1.0.0 alex.apk` — приложение само увидит новую
версию при старте и предложит обновиться.
